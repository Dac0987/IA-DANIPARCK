IA DANIPARCK - prototipo móvil
1. Sube estos archivos a un sitio web con HTTPS.
2. Abre index.html desde Chrome en Android.
3. En Chrome, usa "Añadir a pantalla de inicio" para instalarlo como app.
4. Para convertir archivos grandes en QR compartible entre teléfonos, hay que conectar un almacenamiento web/backend; el QR debe contener un enlace seguro al archivo.
